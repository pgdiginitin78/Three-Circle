# 3 Circles — Engineering, Infrastructure & Mining

A modern, high-performance web experience built with React, Vite, Tailwind CSS, and Framer Motion for **3 Circles**, a premier civil engineering, infrastructure, and heavy industrial solutions contractor in the UAE and GCC.

## 🚀 Features

- **21st.dev Design Language**: Clean luxury dark/light aesthetics with refined gold accents, frosted glass navigation, and responsive typography.
- **Interactive Capabilities**: Core sector showcases (Building Industry, Mining & Crushing, Infrastructure, Excavation) with bespoke assets.
- **Smooth Navigation**: Framer Motion transitions, Lenis smooth scrolling, and full React Router DOM support.
- **Mobile-First Responsive**: Fully responsive across mobile, tablet, and ultra-wide displays.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Lenis Smooth Scroll
- **Icons**: Lucide Icons

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
